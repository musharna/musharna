### Hi, I'm Jaret 👋

PhD student in **Genetics, Bioinformatics & Computational Biology** at Virginia Tech. I build open-source tools at the intersection of plant genomics, machine learning, and LLM tooling.

#### 🔧 What I'm building

**[data-aggregator-mcp](https://github.com/musharna/data-aggregator-mcp)** [![PyPI](https://img.shields.io/pypi/v/data-aggregator-mcp)](https://pypi.org/project/data-aggregator-mcp/) — a unified research-data MCP: search & fetch datasets across Zenodo, DataCite, NCBI omics (GEO/SRA), and literature (PubMed/OpenAIRE) behind one normalized model. `uvx data-aggregator-mcp`

**[plant-genomics-mcp](https://github.com/musharna/plant-genomics-mcp)** [![PyPI](https://img.shields.io/pypi/v/plant-genomics-mcp)](https://pypi.org/project/plant-genomics-mcp/) — 50 genomics tools across 23 backends (Ensembl Plants, Phytozome, UniProt, AlphaFold DB, InterPro, JASPAR, AraGWAS, KEGG, NCBI BLAST, …) with cross-source synthesis.

**[plantcv-mcp](https://github.com/musharna/plantcv-mcp)** [![PyPI](https://img.shields.io/pypi/v/plantcv-mcp)](https://pypi.org/project/plantcv-mcp/) — [PlantCV](https://plantcv.org) as a measurement instrument: plant trait numbers **and the segmentation overlay they were computed from**, and it refuses to return numbers when the segmentation is degenerate.

**[breedsim-mcp](https://github.com/musharna/breedsim-mcp)** [![PyPI](https://img.shields.io/pypi/v/breedsim-mcp)](https://pypi.org/project/breedsim-mcp/) — breeding-scheme simulation over [AlphaSimR](https://github.com/gaynorr/AlphaSimR), built on one rule: a single stochastic run is not a result. Returns per-cycle mean, sd and CI, with no flag that collapses it to a point estimate.

**[jobd](https://github.com/musharna/jobd)** [![PyPI](https://img.shields.io/pypi/v/jobd)](https://pypi.org/project/jobd/) — a self-hostable, GPU-aware job broker for your own machines: capability-tagged routing, and the queue exposed natively to agents over MCP.

**[ghostcite](https://github.com/musharna/ghostcite)** [![PyPI](https://img.shields.io/pypi/v/ghostcite)](https://pypi.org/project/ghostcite/) — deterministic, no-LLM detection of ghost citations: catches author/year that don't match the DOI's CrossRef record, plus retraction flags. Ships as a pre-commit hook and a GitHub Action.
